심폐소생술 순서

  1. 반응·호흡 확인 → 119 신고(스피커폰)
  2. 가슴 중앙을 5~6cm 깊이로 분당 100~120회 압박
  3. AED 도착 즉시 전원을 켜고 패드를 붙인 뒤 음성 안내를 따름
  4. 분석 중에는 환자에게서 손을 뗌, 충격 후 즉시 압박 재개

분류·가정 안내

AED 615건 중 구급차 등 이동형 24건과 기업·공장(D)은 기본 제외. 이용시간은 공공데이터 등록값이며 미등록·오류는 "출입 확인 필요"로 표시합니다. 평일 12~13시 관공서·공공시설·금융기관도 확인 필요. 키워드 규칙에 따른 추정이며 현장 검증 전 값입니다. 예상 소요 = 도보 왕복(직선×1.3, 분속 80m) + 출입 지연(A 0 · B 0.5 · C 1 · D 1.5분) + (1−이용확률)×6분, 이용확률은 이용 가능 0.92 · 확인 필요 0.5로 가정했습니다.
