# 가장 빠른 AED · 안산

> 밤 11시에 실제로 쓸 수 있는 AED는 몇 대인가 — 한양대 ERICA **AI+X 공학융합프로젝트 Team23**

급성심장정지 상황에서 **지금 시각과 내 위치 기준으로 실제로 쓸 수 있는 가장 빠른 AED 한 곳**을 알려 주는 프로토타입입니다.
지도에는 AED가 많아 보이지만 상당수가 관공서·학교·기업 내부에 있어 야간·주말에는 쓸 수 없습니다. 이 앱은 그런 AED를 후보에서 걷어 내고, 출입이 불확실한 곳은 따로 표시합니다.

**데모:** https://kinnjinuuan.github.io/aed-ansan/ (폰 브라우저에서 열고 위치 권한을 허용하세요)

## 주요 기능

- 현재 시각·현위치(GPS) 기준 **1순위 AED 카드** + 후보 6곳, 카카오맵 도보 길안내 연결
- 등록된 이용시간 밖의 AED, 구급차 등 이동형, 공단·기업 내부 AED는 후보에서 **제외**
- 출입이 불확실한 곳(이용시간 미등록·오류, 평일 12~13시 관공서·공공시설·금융기관)은 **"출입 확인 필요"** 로 표시
- 가장 가까운 곳이 1순위가 아닐 때 그 이유를 한 줄로 설명
- 가까운 후보가 1.5km보다 멀면 "119 먼저 신고" 안내
- 시연용 설정: 위치·요일·시각을 바꿔 낮/밤 차이를 확인 (설정 버튼)

## 예상 소요 계산(가정값)

`예상 소요 = 도보 왕복 + 출입 지연 + (1 − 이용확률) × 6분`

- 도보 왕복: 직선거리 × 1.3, 분속 80m
- 출입 지연: A 0 · B 0.5 · C 1 · D 1.5분
- 이용확률: 이용 가능 0.92, 출입 확인 필요 0.5

위 값은 **가정**이며, 현장 검증(저녁에 AED 20~30곳 직접 확인)으로 보정할 예정입니다.

## 한계

- 이용시간은 공공데이터 등록값이라 실제와 다를 수 있고, 갱신일을 알 수 없습니다.
- 분류는 키워드 규칙이라 오류가 있을 수 있습니다(예: 기업 연구소가 "캠퍼스"라는 단어 때문에 학교로 분류되던 6건은 수동 보정).
- 도보 시간은 실제 경로가 아니라 직선거리 기반 추정입니다.
- 공휴일은 자동 판별하지 않고, 설정에서 직접 선택해야 합니다.
- **의료기기 앱이 아니며 응급 상황에서는 반드시 119 안내를 따르세요.**

## 개발·AI 활용 이력

앱 코드와 분류 스크립트는 Claude(Anthropic)와 대화하며 작성했고, 결과는 팀이 검토·검증합니다.
카카오 지도 JavaScript 키가 `index.html`에 포함되어 있습니다. 키는 등록된 도메인(이 Pages 주소, localhost)에서만 작동합니다.

## 로컬 실행

폴더에서 `py -m http.server 5500` 실행 후 `http://localhost:5500/` 접속 (`file://`로 열면 지도가 뜨지 않음).
